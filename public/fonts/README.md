# ProjectQuest typography

Manrope (variable weights 200–800) is the interface and body typeface. DM Serif Display provides the characterful display headings, in regular and italic. Both are self-hosted WOFF2 files: no font service, cookies, or network request is needed to read the game.

Sources: verified npm packages `@fontsource-variable/manrope@5.3.0` and `@fontsource/dm-serif-display@5.3.0`, distributed by [Fontsource](https://fontsource.org/). The accompanying SIL Open Font License files retain the original font copyright and licence notices. Only Latin font subsets are bundled; system fallback fonts cover unsupported characters.
